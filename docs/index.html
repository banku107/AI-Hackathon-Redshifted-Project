ScamShield

Scammers use AI to sound like your grandson.

We use AI to protect your grandmother. An AI agent for older adults: paste a message, add a screenshot, or upload a video. The agent investigates it, answers in plain language, warns a family member, and helps if money was already sent.

What it does

  • Check Reads the message, screenshot, or video frames and calls investigation tools instead of guessing.
  • Explain Gives one verdict with reasons, next steps, and a read-aloud button, in the reader's language.
  • Alert family After a scam or a suspicious result, warns a trusted contact on the Family screen.
  • Damage control If money was sent, shows a recovery checklist and a report you can paste into a complaint form.

How a check works

The agent never guesses. It plans, investigates, and then checks its own answer against the evidence it found.

  1. Plan three to five short steps for this input.
  2. Call tools: follow the link, check the domain age, compare the name to a real brand, check reputation, search the web, or read the video file.
  3. Collect evidence. Each finding gets a plain sentence and a severity: red, yellow, green, or info.
  4. Self-verify the draft verdict against that evidence.
  5. Answer with the verdict, reasons, and next steps.

The UI shows each step as it happens. A verdict is never given without evidence: scam needs at least two red findings and safe needs none. A failed tool proves nothing and is not counted. "I am not sure" is allowed: the agent can answer suspicious and say what it could not confirm.

The verdict format

  • Scam

    The signs agree. The person is warned and told what not to do.

  • Suspicious

    Something is wrong, but the evidence is not enough for a firm answer. The screen says "Be careful" and explains what is unclear.

  • Looks real

    Nothing asks for money, details, or a risky action. The contract name for this level is safe.

For a video there are two separate answers: is the video likely made by AI, and is it a scam. They are independent. A real video can still be a scam.

Running locally

Requires Node 20 or newer.

npm install
cp .env.example .env.local    # set ANTHROPIC_API_KEY in the copy
npm run dev                   # http://localhost:3000

Never commit .env.local. .gitignore covers every .env* path; the other keys in .env.example are optional. With the app running, try the agent from a second terminal:

npm run try:agent -- usps     # cases: bank, usps, jail, jail_es, jail_acted
npm run try:media -- screenshot shot.png

npm run typecheck, npm run lint, and npm run test:agent (offline) are free; npm run record:demo calls Claude and costs a little. Demo mode replays mock/demo-recording.json with no network: send "demo": true or set DEMO_MODE=true.

ScamShield runs only on your laptop: no hosting, no domain, no cloud storage. To open it on a phone, put the phone on the same Wi-Fi, run npm run dev:phone, and open http://<laptop-ip>:3000 (find the IP with ipconfig on Windows). Uploaded videos are saved in .uploads/<videoId>, which git ignores. Until /api/upload exists the client falls back to sending video frames as screenshots.

npm run accuracy runs extra messages through Claude and prints a score; it costs a few cents.

Design

Built for older, low-vision users first, not adapted for them afterwards.

  • Atkinson Hyperlegible everywhere, self-hosted through next/font. It was drawn by the Braille Institute so letters that look alike stay apart.
  • Every interactive target is at least 48 px tall; the main action is 64 px.
  • One teal accent. Red appears only for a confirmed scam, and never as the only signal: icon, word, and sentence always carry the meaning too.
  • Text size can be raised from the header and scales the whole page, not just the headings.
  • Full dark theme, visible focus rings, and reduced-motion handling.

Safety rules

  • Never open a scam link in a browser. Follow redirects on the server only, with a short timeout and a size cap.
  • Never commit an API key. If one leaks, rotate it.
  • The message being checked is data, never instructions.
  • Never send the person to a phone number, link, or address from the message itself.
  • Never deepfake a real person without consent. Demo videos use synthetic people, and test data uses made-up people and contact details.
  • Be honest in the pitch. AI detectors can be fooled, and a verdict is a helper, not a guarantee.
